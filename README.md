## ⏱️ **Full-Stack Employee Time Tracking Tool**

This project is a comprehensive, full-stack application designed for **employee time tracking and management**. It was developed as part of the **Software Technology** course at **HS Esslingen** during the **Winter Semester 2025/2026**.

-----

## 🌟 **Features**

TimeMaster provides a centralized platform for managing employee working hours and absences, including:

  * **Employee Time Tracking:** Simple and accurate recording of daily work hours.
  * **Vacation and Sick Leave Management:** Tracking, submission, and approval of time-off requests.
  * **Flex Accounts:** Management and monitoring of flexible working hours balances (e.g., overtime, accumulated extra time).
  * **Employee Management:** Centralized administration of employee data and access control.

-----

## 🛠️ **Technology Stack**

The application is built using a modern and robust technology stack:

  * **Language:** **TypeScript**
  * **Frontend:** **React** (for a dynamic and responsive user interface)
  * **Backend:** **Express.js** (for routing and middleware) running on **Node.js** (as the server environment)
  * **Database:** **PostgreSQL** (for reliable and scalable data storage)
  * **Design:** **TailwindCSS**

-----

## 🎓 **Project Context**

This project was developed under the supervision of the faculty in the **Software Technology** module at **Hochschule Esslingen (HS Esslingen)**. It serves as a practical implementation exercise covering full-stack development principles, database integration, and modern web application architecture.
